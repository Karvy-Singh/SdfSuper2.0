  \item \textbf{Brief-}
    The Desktop Chat Application is a client-server-based communication system developed in C++ that enables real-time messaging, file sharing, and image sharing between users. The application follows a structured approach using Object-Oriented Programming (OOP) principles, ensuring modularity, scalability, and maintainability. The primary goal of this project is to create a robust and efficient chat system tailored for desktop environments. 

  It comes with user authentication and a GUI for ease, with using concepts like abstraction, encapsulation, inheritance and polymorphism and SQL for data storage, it main features includes networking, GUI Framework, DB management/ File Handling
